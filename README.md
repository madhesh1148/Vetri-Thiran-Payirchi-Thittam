# LegalEase: AI-Powered Legal Document Generator

## Ready-to-run college project
Features:
- Login and signup
- Dashboard
- Six legal-document draft types
- Smart structured draft generation
- SQLite storage
- Document history
- Download and delete
- Responsive professional UI
- Legal disclaimer

## Run
1. Install Python 3.10+
2. Open terminal in this folder
3. `python -m venv venv`
4. Windows: `venv\Scripts\activate`
5. `pip install -r requirements.txt`
6. `python app.py`
7. Open `http://127.0.0.1:5000`

## Important
This is a college demonstration. The current "AI" layer is a smart template/drafting engine; it can later be connected to a reviewed LLM/API. Generated content is not legal advice.
